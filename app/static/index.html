iPhone tips for best quality
  • If the picker shows "Compressing Video…", your iPhone is shrinking the file before upload. For full quality, save the clip to Files first (Share → Save to Files), then choose it with Choose File / Browse.
  • Slo-mo clips recorded at 120/240 fps can be slowed down smoothly. Set a clip's Slow-mo to On to force it.
  • Uploads go up in small pieces and resume after a dropped connection. Keep this page open until every bar is full. You can re-pick the same file to resume.
  • If Shorts Lab is reachable on your home network (see the README), opening it by the server's local address while on Wi-Fi skips the internet round trip and uploads faster.
